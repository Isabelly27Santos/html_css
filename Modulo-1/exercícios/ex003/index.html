Testando Carregamento de Imagens

Abaixo você vai ver uma imagem do tipo PNG que está na mesma pasta:

Imagens PNG mantém melhor a qualidade e permite fundo transparente, porém pode gera arquivos maiores. É ideal para logos, ícones e imagens com transparência.

Podemos também carregar imagens que estão em sub-pastas, veja um exemplo do tipo JPEG:

Imagens JPEG comprime bastante a imagem, deixando o arquivo menor, mas pode perder um pouco de qualidade. É ideal para fotos e imagens com muitas cores.

Para sites prefira usar sempre JPEG para não pesar o carregamento do site, e escolha a dimensão de imagem necessária, pois não adianta ter uma imagem salva no site de 4000x2000 se no CSS você vai reduzir ela para 200x300
